abnormalDay

Yet another attempt to create a game using the Sauerbraten engine

Building

  1. Download TDM GCC 10.3.0
  2. Install TDM GCC 10.3.0
  3. Download mingw32-make
  4. Download Premake
  5. Build dependencies
  6. Move .dll files of dependencies to <thisProjectFolderPath>\lib\ folder
  7. Move .h files of dependencies to <thisProjectFolderPath>\include\ folder
  8. Run cmd.exe
  9. Execute the following commands: 
    
> set "PATH=%PATH%;C:\TDM-GCC-64\bin\;"
> cd <thisProjectFolderPath>
> <premakeExePath> gmake
> <mingw32MakeExePath> config=release_32bit

    Where <thisProjectFolderPath> is something like C:\Users\zar-s\projects\abnormalDay\

    Where <premakeExePath> is something like C:\Users\zar-s\soft\premake5.exe

    Where <mingw32MakeExePath> is something like C:\Users\zar-s\soft\mingw32-make.exe

    After executing these commands <thisProjectDir>\bin\game.exe file will be created
